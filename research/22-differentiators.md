# 22. Differentiators

Date: 14 November 2026. “Demand” is only what a public page actually showed. Search volumes for these phrases were not found unless a number is printed here.

## Worth building in the test

**A visible answer key, not a member key.** K5’s FAQ says the key is usually on page 2, and that separating the question page from the answer page is a paid feature ($23.95/year). Autocomplete on 14 November 2026 suggests “answer key worksheet” and “answer key super teacher worksheets” from the stem “answer key worksheets”. A Reddit thread in r/TutorsHelpingTutors (13–14 July 2025) recommends K5 because one small concept has about six sheets that get harder. Teachers already get keys from K5. They do not get a free, separate key or a preview. Effort: low, because the key is the same records as the problems. SEO: moderate. The query language includes “with answers”. Do not put every answer in the HTML. One worked example on the page, the rest in the PDF, so an AI Overview has less to lift (file 05).

**Three levels on one URL.** The same Reddit comment is the evidence: teachers notice that K5 scales difficulty across sheets. Autocomplete suggests “differentiated math worksheets” and nothing more specific. Volume: not found. Effort: low if the generator already has a support set and an extra set. SEO: low if each level is its own URL, because that splits one query across three near-duplicates. Put the levels on the skill URL. K5 already has six static PDFs. Matching that is the minimum. Beating it means the levels are labeled (support, on-level, extra) and the preview is free.

**No login on the free sheet.** K5’s FAQ says most sheets need no login. Education.com’s free plan is the one with a limit, from the secondary review in file 01, not re-read on their terms page. Super Teacher is the login wall: the elementary-teacher thread of 19–20 December 2024 has teachers naming the $25-a-year price as the cost of the full library, and one calls the built-in worksheet maker worth it. A new site cannot beat Super Teacher’s library. It can beat the wall for a parent who wants one sheet tonight. SEO: high, because the file has to be on a URL Google can fetch.

**Print-clean PDF.** No teacher quote in this pass says “I want fewer colors”. The measurement is the product: K5’s FAQ says the files are PDFs, and the quarter-hour PDF extract is a black worksheet with the key on the next page. Effort: the renderer. SEO: none by itself. It is why a teacher comes back, which is direct traffic, not a ranking factor we can cite.

**One skill, not a catalog.** Math-Drills’ ranking URLs for subtraction and addition are 4,900 and 5,800 words of links. That is the page a new site can be clearer than, on the query that is actually one skill. It is not a weakness of K5’s quarter-hour page, which is already one skill. SEO: this is the whole bet for queries whose number-one result is a hub. It is a weak bet against K5’s skill pages.

**A new problem set without a new URL.** Autocomplete from “math worksheet generator” includes “free”, “ai”, “multiplication”, and “addition and subtraction”. Teachers in the December 2024 elementary thread mention WorksheetWorks and Super Teacher’s maker, and one non-teacher mentions ChatGPT. Demand for a generator is real as a suggestion, not as a volume. Math-Drills already ships many static versions. A button that redraws numbers on the same page is useful and should not create an indexable URL. SEO value of the button: low. SEO risk if every redraw is a URL: high (file 24). Build the button. Prebuild the default PDF so the page works with JavaScript off.

## Do not lead with these

**Google Classroom / Easel.** K5 charges for Classroom sharing. Autocomplete for “worksheets google classroom” returns “worksheets for google classroom”. No volume. A PDF is already something a teacher can attach. An Easel-style interactive layer is a second product. Effort: high. SEO: low. Skip in the 50-URL test.

**Weekly packets.** “weekly math packet grade 2” did not hold as a suggestion. The returned suggestions were “math packet grade 2” and an unrelated schedule phrase. Weak demand signal. A packet is a bundle of the skill PDFs, which is a phase-2 zip, not 50 extra URLs.

**Spanish versions.** “spanish math worksheets grade 2” returned no suggestions on this pass. Not found. Do not build a Spanish mirror to chase a demand we could not see.

**Standards tags.** Common Core Sheets ranks for “common core math worksheets grade 3” by being the standards index. Tags on a skill page match how a coach filters. They do not beat that domain on that query. Put the code on the page. Do not put it in the brand (file 08).
