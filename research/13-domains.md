# 13. Domain candidates

Checked 14 November 2026 against Verisign’s public RDAP: `https://rdap.verisign.com/com/v1/domain/<name>.com`.

HTTP 404 means Verisign returned no domain record. That usually means the name is not registered. It does not mean it can be bought at the standard fee, that it is free of a trademark, or that a registrar will sell it. Nothing was registered. No WHOIS contact was opened. A 200 response with status and dates means the name is registered.

About 30 names were brainstormed, then more were checked after the first pass came back mostly taken. Short, obvious compounds (`sheetnest`, `worksheetly`, `printnest`, `k8sheets`) were already gone. Several had been registered in 2026, which fits the clone wave in file 02.

## Names that were not the brand

Avoid, even if a lookup later says free: anything with “Common Core”, “TEKS”, “SOL”, “STAAR”, “Worksheets” plus a superlative that apes Super Teacher, and anything that embeds “K5” or “Math-Drills”. File 08 covers the standards marks. The incumbents’ brands are not available as a style.

Public email, once a name is chosen: `contact@<that-domain>` only. No personal name on the site, in the PDF footer, or in the WHOIS if a privacy option exists. WHOIS privacy was not researched domain by domain. Check it at purchase time. This project did not purchase.
