# 26. Topic scores and the first 50 URLs

Date: 14 November 2026. This is a ranking method, not a traffic forecast.

## The score

Each topic gets four marks from 1 to 5. Higher is better for us. There is no search volume in the sum unless one was printed on a Semrush page, and none of these 50 had one.

| Mark | 5 | 3 | 1 |
| --- | --- | --- | --- |
| Demand | Not used. No topic here has a verified volume. | Autocomplete on 14 Nov 2026 shows the skill or the grade-plus-skill. | Curriculum only. No suggestion captured. |
| SERP opening | Not awarded. No query in the sample had a weak top five. | Number-one result is a catalog (Math-Drills hub, K5 grade menu), so a single-skill page is a clearer document. | Number-one result is already a single-skill page (the K5 quarter-hour page). |
| AI Overview | Overview absent. Not seen in the 10-query check. | Overview explains the skill and does not embed a file. This is the observed case, so worksheet queries sit here unless noted. | Overview would include the problems. Not observed. |
| Seasonality | Evergreen. | School-year practice that is useless in July. Still a 5 if the skill is taught all year. Holiday packs are not in this 50. | A one-month query. None of these 50. |

Beatable friction is a note, not a fifth score: K5 means the preview and the separate key are paid; Math-Drills means the ranking page is a catalog or the leaf is old.

Total is demand + opening + overview + seasonality, out of 20. Ties break toward the skill whose current number-one page is a catalog, because that is the only structural opening we measured.
